| F-01 | Japanese Labor Standards Act Art 37: Night Work Premium Calculation | P0 | FAIL | `PayrollService.java` lines 138-145 (`calculateDailyPay` call) and `applyStatutoryMonthlyRounding` (lines 218-225). | **Critical Logic Error:** The code calculates Night Allowance and Overtime Allowance independently using a flat 25% premium. However, Japanese Labor Standards Act Article 37(1) mandates that if night work (22:00-05:00) overlaps with overtime (>8h/day), the premium must be **50%** (25% night + 25% overtime), not additive separate lines that might sum incorrectly or fail to apply the combined rate correctly in edge cases. More critically, the `PayrollCalculator.calculateDailyPay` is called with `nightWorkMinutes` and `overtimeMinutes` separately. If the system does not explicitly calculate the *overlap* minutes and apply a 50% premium to that specific overlap, it violates the law. The current code structure suggests `nightAllowance` and `overtimeAllowance` are calculated on their respective total minutes. If a worker works 10 hours at night, 2 hours are overtime. The law requires 50% premium on those 2 hours. If the code pays 25% on all night hours and 25% on all overtime hours, it results in 50% for the overlap, which is correct *if* the base pay is handled correctly. However, the statutory rounding logic (`applyStatutoryMonthlyRounding`) recalculates premiums based on *total* rounded hours. It calculates `overtimeHourlyPremium` (25%) and `nightHourlyPremium` (25%) separately. It does **not** account for the "Night + Overtime" overlap category which requires a distinct 50% premium calculation in the statutory monthly rounding context (Ministry of Health, Labour and Welfare Notification No. 150). The current implementation likely underpays or miscalculates the statutory monthly rounding for overlapping hours. |
| F-02 | Japanese Labor Standards Act Art 37: Break Time Deduction | P1 | WARN | `PayrollService.java` line 138 (`att.getNetWorkMinutes()`). | The code relies on `att.getNetWorkMinutes()`, `att.getNightWorkMinutes()`, and `att.getOvertimeMinutes()` from `AttendanceDto`. The `PayrollService` does not perform this calculation; it assumes the `AttendanceDto` provides pre-calculated, legally compliant minute counts. If the upstream `AttendanceService` fails to deduct night breaks from the night work total (treating them as regular breaks), the night work premium will be overpaid. Since this service is the final gate for payroll, it lacks a defensive validation to ensure `nightWorkMinutes` does not include break times. Recommendation: Add a validation check or ensure the `AttendanceDto` contract explicitly guarantees net-of-break night hours. |
