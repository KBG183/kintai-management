| F-01 | Japanese Labor Standards Act Art 37: Night Work & Overtime Calculation Logic | P0 | FAIL | `PayrollService.calculatePayrollForStaff`: `totalNightAllowance += dailyPay.nightAllowance();` and `totalOvertimeAllowance += dailyPay.overtimeAllowance();` are summed independently. `PayrollExcelExporter` displays these as separate columns. | **Critical Legal Compliance Failure**: The code calculates Night Allowance and Overtime Allowance independently and sums them. However, Japanese Labor Standards Act Article 37(2) mandates that when night work (22:00-05:00) overlaps with overtime (>8h/day), the premium rate must be **50%** (25% night + 25% overtime), not additive separate calculations that might result in double-counting or incorrect base application if not handled in `PayrollCalculator`. More critically, the code does not explicitly handle the "Night + Overtime Concurrent" scenario in the visible service logic, relying entirely on `PayrollCalculator.calculateDailyPay`. If `PayrollCalculator` simply adds `nightAllowance` and `overtimeAllowance` based on separate minute counts without checking for overlap, it violates the law. The Excel export also lacks a specific "Night Overtime" column, obscuring the 50% premium calculation required for audit trails. |
| F-02 | Payroll Math & Rounding: Statutory Monthly Rounding Application | P1 | WARN | `PayrollService.applyStatutoryMonthlyRounding`: `int roundedOvertimeHours = PayrollCalculator.StatutoryRounding.roundMonthlyHours(payroll.getTotalOvertimeMinutes());` | **Rounding Logic Risk**: The code applies statutory rounding (30-minute boundary) to the *total* monthly minutes before calculating the allowance. While this aligns with the "Monthly Total" interpretation of the Ministry of Health, Labour and Welfare notice, it is only applied if `appliedHourlyWage != null` (i.e., single wage rate). If a staff member has multiple wage rates in a month (e.g., promotion mid-month), `appliedHourlyWage` is null, and the statutory monthly rounding is **skipped**, falling back to daily sums. This creates an inconsistency where staff with single wages get statutory rounding, but those with multiple wages do not, potentially violating the uniform application of the rounding rule. |
