# Hermes v2 미해결 사항 및 추가 검증 필요 목록 (최종 개정본)

## 1. 개요
본 문서는 Hermes 로컬 감사 시스템 2차 정밀 개선 개정안 수립 과정에서 도출된 기술적 미해결 사항, 실제 운영 환경 적용 전 검증되어야 할 가설, 그리고 사용자/도메인 전문가의 검토가 필요한 항목들을 정리한 목록이다.

## 3. 도메인 전문가(사용자) 확인 및 정책 확정 내역
1. **[Silent Fallback 완전 차단 정책 확정]**:
   - `report.json`이 존재하지만 스키마나 검증을 통과하지 못한 경우, v1 마크다운 정규식 파서로 자동 대체하지 않고 즉시 `AUDIT_FAILED (Exit Code 10~13)`로 중단(Hard-Gate)하는 보안 정책 채택 확정.
2. **[FAIL 3대 증명 방식 공식 확정]**:
   - 실행 테스트 증명(단위 테스트/에러 스택), 정적 코드 분석 증명(자명한 취약점/누락), 수학적 반례 증명(단수처리 오차) 3대 증거를 대등하게 인정하여 거짓 음성(False Negative) 방지 확정.
3. **[토큰 비율 및 컨텍스트 한도 안정성 최우선 동결]**:
   - 글자수 / 3.0 공식 및 `num_ctx: 24576`을 공식 표준으로 동결 확정.

4. **[Exit 20 상태 관리자 연동]**: `state_manager.ps1`은 아직 수정하지 않았으므로, v2 verifier의 provenance Exit 20을 `AUDIT_INCOMPLETE`로 매핑하는 작업은 미완료다.
