# KINTAI 製品デモ動画 進行台本

## デモの目的

AI監査ツールを見せる動画ではなく、スタッフの勤務記録がオーナーの承認、給与計算、Excel台帳出力へつながるKINTAIの業務フローを見せます。

## 撮影方針

- オーナー1名、スタッフ6名
- スタッフごとに時給・交通費を変える
- アカウント、スタッフ、時給、基準勤怠だけを事前に準備する
- 撮影中に作成する申請・承認・修正結果は事前に確定させない
- 月間カレンダーには背景用の確定シフトだけを表示し、中心となるシーンは空いている日付から作成する

スタッフを10名まで増やすと表とカレンダーが複雑になり、動画の中心である業務フローが見えにくくなります。6名で代表ケースを分ける構成を推奨します。

## 撮影前の準備

1. 新しい隔離デモDBを作成するか、`scripts/prepare_video_demo_state.sql`を適用します。
2. ブラウザーは `http://127.0.0.1:8082` を使用します。
3. デモアカウントはローカルシードの値を使用し、パスワードを動画・証跡に表示しません。
4. 撮影に使う空の日付を固定します。

## 撮影順序

### 1. スタッフログイン

スタッフでログインし、現在の本人名を画面上部で確認します。

説明:

> スタッフは自分のシフトと勤怠だけを確認し、出退勤の打刻と修正申請を行います。

### 2. シフト確認と打刻

月間カレンダーで自分のシフトを確認し、出勤、休憩開始、休憩終了、退勤を順に実行します。

説明:

> シフト予定と実際の勤怠を分けて記録し、給与計算の元データを作ります。

### 3. 勤怠修正申請

確定済み勤怠に対して修正申請を作成します。申請IDとPENDING状態を画面で確認します。

### 4. オーナーログイン

オーナー画面へ移動し、対象店舗のスタッフ全体のシフトとPENDING申請を確認します。

説明:

> オーナーはスタッフ本人の入力をそのまま信頼せず、店舗所属と承認状態を確認して勤怠を審査します。

### 5. 勤怠承認と給与計算

修正申請を承認し、対象月の給与を再計算します。深夜・時間外・分割勤務の計算結果を確認します。

### 6. Excel出力

給与を確認した後、Excel台帳をダウンロードします。ファイルサイズ、XLSX形式、対象月、画面表示額との一致を確認します。

## 締めの説明

> KINTAIは、スタッフの打刻からオーナーの審査、給与確定、Excel出力までを一つのデータフローとしてつなぎます。今回のデモは隔離DB上の実演であり、本番運用や法令全体への適合を示すものではありません。
