## 경로 변경 규칙

경로를 이동하거나 이름을 바꾸면 이 파일을 먼저 갱신하고, 스크립트·활성 문서·증적서의 참조를 확인한다. 이동 전후 파일 해시가 다르면 단순 이동으로 처리하지 않고 내용 또는 인코딩 변경으로 기록한다.
