# AGENTS.md 조항 이관 검토표

원본은 `AGENTS_legacy_20261113.md`에 보존했고 최상위 문서를 간결화했다. 아래는 이관 검토 내역이다. 과거 날짜별 완료 표시는 실측 검증 결과가 아닌 기존 계획 기록이다.

|---|---|---|
| 0.1–3 소통과 서식 | 유지·간결화 | 사용자에게 진행 상황을 전달하고 존댓말, 물결표·취소선 금지 선호를 존중한다. 긴 정형 복명복창 의무는 완화 제안. |
| 0.4 모델과 장비 | 이관 | 실행마다 실제 모델 태그와 환경을 기록한다. 7B 자동 폴백 여부는 현재 27B 우선 정책과 대조하며 임의로 변경하지 않는다. |
| 0.5 일본어 산출물 | 유지 | 포트폴리오 코드 주석, UI와 일본어 기술 산출물의 기존 일본어 방침을 유지한다. 한국어 설명과 기존 한국어 증적서는 병행한다. |
| 0.6, 11, 14 전체 감사 | 승인·우선 적용 | 사용자가 위험 기반 감사 방식을 승인했다. 루트 문서 상단의 우선 적용 규칙을 따른다. 기존 문구는 이력으로 남아 있어 완전 이관 시 정리한다. |
| 0.7–9 감사 보고·증적 | 유지·이관 | 결함, 위험, 조치, 재검수와 실제 메트릭을 증적에 기록하고 한·일 문서의 일관성을 확인한다. 미실행 메트릭은 생성하지 않는다. |
| 0.10, 12, 13 저장·마감 | 보존·재검토 | 기존 사용자 명시 지시 원칙과 승인 절차를 유지한다. 자동 외부 반영, 버전과 일차의 강제 일치는 정책 충돌로 별도 검토한다. |
| 0.15–16 백그라운드 | 완화 제안 | 도구별 상태 확인을 사용하고 프로세스 종료는 대상과 권한을 확인한다. 출처 불명 프로세스를 일괄 종료하지 않는다. |
| 0.17 독립 감사 | 유지 | 기능 단위 관련 계층과 테스트를 포함하고 Finding과 근거를 연결한다. LAB 벤치마크 계획은 원본에서 보존하고 현재 일차를 임의 변경하지 않는다. |
| 0.18 인코딩 | 유지 | 파일의 기존 인코딩과 BOM을 확인하여 보존하고 UTF-8을 명시한다. 콘솔 표시 오류를 파일 손상으로 단정하지 않는다. |
| 0.19–20 사실·RTM | 유지 | 사실과 추정, 구현과 검증을 분리하고 실패 이력과 요구사항 추적을 보존한다. 문서 간 상태 정의는 추가 정합성 검토가 필요하다. |
| 1 역할 및 모델 | 조정 제안 | 사용자 선택에 의한 단일 작업자, Qwen 검토와 선택적 Codex 역할을 반영한다. 실제 엔드포인트는 미확인. |
| 2 감사 모드 | 보존·검토 | 기존 사전 감사 및 재감사 절차를 원본에 보존한다. 위험 기반 완화는 위 0.6과 같은 정책 결정이 필요하다. |
| 3 일차 계획 | 보존 | 기존 표를 삭제하지 않으며 현행 SRS·RTM·일차 자료와 대조 전 상태를 확정하지 않는다. |

사용자 승인에 따른 위험 기반 감사 정책은 적용되었다. 나머지 세부 운영 규칙의 이관과 실행 도구의 강제 여부는 추가 검증이 필요하다.
