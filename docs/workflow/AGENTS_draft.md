# Kintai 프로젝트 운영 지침 초안

이 문서는 검토용 초안이다. 실제 적용 중인 규칙은 프로젝트 루트의 `AGENTS.md`이며, 이 초안은 그 파일을 대체하지 않는다.

## 범위와 우선순위

- 프로젝트 작업은 `C:\dev\kintai`를 기준으로 한다. 현재 사용자 지시와 적용 가능한 상위 시스템 지침을 우선한다.
- 프로젝트 내부 규칙이 충돌하면 현재 사용자 지시를 확인하고, 이 문서에서 정한 원칙과 각 분야의 기준 문서를 대조한다. 충돌을 숨기거나 근거 없이 임의의 완료 판정을 하지 않는다.
- 이미 존재하는 사용자 변경과 감사 기록을 보존한다. 파일 이동, 삭제 또는 덮어쓰기는 범위와 복구 가능성을 확인한다.

## 역할과 작업 방식

- Antigravity는 사용자 지시에 따라 구현, 테스트, 증적 작성과 기존 Hermes를 통한 Qwen 감사 요청을 수행한다.
- Qwen 27B는 독립 검토자로서 입력된 자료에 대한 의견을 제시한다. Qwen의 판단은 테스트 결과를 대신하지 않는다.
- Codex는 사용자가 요청한 때에만 작업한다. 사용자 판단 없이 다른 AI를 자동 호출하거나 작업을 넘기지 않는다.
- 사용자가 작업 범위와 최종 판단을 결정한다. 한 번에 한 작업자만 해당 파일을 수정하며, 교체는 사용자가 결정한다.
- Day별 요구사항, SRS와 설계, RTM 및 현재 작업 기록을 먼저 확인하고 해당 일차를 점진적으로 진행한다. 과거 계획표는 현재 완료 상태의 증거로 간주하지 않는다.

## 감사와 증적

- 변경 범위와 위험에 맞게 테스트와 검토를 계획한다. 보안, 급여 및 동시성 등 위험이 큰 변경은 관련 자료를 모아 독립 감사를 수행한다. 감사 범위와 결과, 미검증 사항을 기록한다.
- `PASS`는 감사 의견이며, `VERIFIED`는 해당 요구사항과 환경에 맞는 실행 증적을 확인한 경우에만 사용한다. 환경별 결과와 실패, 차단, 미실행을 구분한다.
- 한국어와 일본어 증적서는 기존 양식에 맞춰 함께 갱신하고, 결과와 수치가 서로 일치하는지 확인한다. 실패한 시도와 수정 이력도 보존한다.
- Qwen의 모델 태그, 실제 접속 대상, 사용한 스크립트, 입력 및 결과 해시와 실측 수치는 실행별 증적에 기록한다. 확인되지 않은 값을 확정하지 않는다.
- 기존 `validate_qwen_audit_input.ps1`은 추가 검증이 필요한 도구다. 독립 실행이나 선택적 연결만으로 모든 누락이 자동 차단된다고 주장하지 않는다.

## 보고와 권한

- 확인한 사실, 추정, 검증하지 못한 항목을 구분하고 근거 파일과 실행 환경을 명시한다. 과장된 안전성이나 완료를 단정하지 않는다.
- 실행, 삭제, 외부 전송, 배포 등은 사용자가 허용한 작업 범위에서 수행한다. 저장소에 대한 외부 반영은 명시적으로 요청받은 경우에만 수행한다.
- 스크립트의 경로, 모델 및 환경 변수는 실제 설정을 읽어 확인한다. 비밀정보를 보고서에 기록하지 않는다.
